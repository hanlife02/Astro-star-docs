# 参与贡献

欢迎从小改动开始。一个清晰的 Issue、一张移动端截图、一个可复现的 Bug、一个更顺手的组件，或者一段部署说明，都能让 Astro-star 更容易维护和复用。

## 适合提交的内容

| 类型     | 内容                                       |
| -------- | ------------------------------------------ |
| Bug      | 构建失败、页面错位、路由异常、暗色主题问题 |
| 体验优化 | 移动端布局、可访问性、交互细节、加载状态   |
| 主题能力 | 新组件、内容卡片、归档视图、友链展示方式   |
| 文档     | 搭站教程、部署记录、配置说明、迁移经验     |
| 集成     | 搜索、评论、订阅、统计和更多部署平台       |

## 提交前检查

```bash
pnpm check
pnpm format:check
pnpm build
```

## 贡献原则

- 组件不硬编码业务内容。
- 样式放在 `src/style/`。
- 移动端优先。
- 不提交密钥、私钥和真实生产环境凭据。
